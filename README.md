# Law Links

Сервис, который находит в русском тексте ссылки на нормы права и раскладывает их по полям: закон, статья, пункт, подпункт.
Групповое задание №1 по NLP, условие — в [homework_1/README.md](homework_1/README.md).

## Что получается на выходе

| Текст | Результат |
|-------|-----------|
| `пп. 1 п. 1 ст. 374 НК РФ` | закон 15, статья 374, пункт 1, подпункт 1 |
| `пп. 1, 2, 3 п. 2 ст. 3 НК РФ` | три ссылки, различаются подпунктом |
| `в статье 125 Арбитражного процессуального кодекса` | закон 0, статья 125 |
| `ст. 5 Указа Президента РФ №240` | закон по номеру из базы, статья 5 |
| `Согласно ст. 15 ГК РФ … статья 393 названного Кодекса` | две ссылки на закон 5 |
| `ст. 17 Конституции Российской Федерации` | ничего: закона нет в базе |

## Запуск

Docker:

```bash
cd homework_1
docker build -t law-links-service .
docker run -d -p 8978:8978 --name law-links-container law-links-service
curl -X POST http://localhost:8978/detect -H "Content-Type: application/json" \
     -d '{"text": "Согласно статье 23 Налогового кодекса и ст. 145 Гражданского кодекса"}'
```

Без Docker (Python 3.12):

```bash
cd homework_1
pip install -r requirements-dev.txt
make run          # то же, что uvicorn main:app --port 8978
```

Остановить и убрать контейнер: `docker stop law-links-container && docker rm law-links-container && docker rmi law-links-service`.

| Метод и путь | Назначение |
|--------------|------------|
| `POST /detect` | тело `{"text": "..."}`, ответ `{"links": [{law_id, article, point_article, subpoint_article}]}` |
| `GET /health` | `{"status": "healthy"}` |
| `GET /docs` | Swagger |

Контейнер поднимается примерно за 3 секунды (строится индекс названий законов), занимает около 95 МБ памяти,
образ весит около 260 МБ, процесс работает не от root, в образе настроен `HEALTHCHECK`.

## Устройство

Конвейер собирает функция `detect_links` в `main.py`. Остальные модули друг друга не импортируют.

```
текст ──► extract_links ──► [RawLink] ──► find_law(название) ──► law_id ──► expand ──► [LawLink]
```

| Модуль | Вход → выход | Суть |
|--------|--------------|------|
| `link_extractor.py` | текст → список `RawLink` | правила на регулярных выражениях: уровни ссылки, значения, вырезание названия закона, закон из контекста |
| `law_matcher.py` | название → `law_id` или `None` | нормализация и лемматизация алиасов, индекс строится один раз при старте |
| `number_parser.py` | `RawLink` + `law_id` → список `LawLink` | разбор перечислений, декартово произведение, удаление дублей |
| `contracts.py` | — | общий тип `RawLink` |

Что умеет извлечение: оба порядка записи (`пп. 1 п. 2 ст. 3` и `ст. 3 ч. 2 п. а`), сокращения и падежи (`ст.`, `статьёй`, `подп.`, `п.п.`),
значения `12`, `4.6`, `43.2-6`, `5 и 6`, `«б»`, «части первой», опечатки (`пунта`, `п. р`), перенос строки перед названием закона.
Название закона вырезается целиком, если это кодекс (`УК РФ`, `ук рф`), закон или указ с датой и номером, распоряжение, стандарт бухучёта.
Если закон справа не назван, берётся закон из контекста: `настоящего Федерального закона`, `названного Кодекса`, `Согласно УК РФ … ст. 105`.

Что умеет определение закона: совпадение названия с алиасом, затем самое длинное однозначное вхождение, затем номер акта
(`№ 580-ФЗ`) с уточнением по дате или названию. Неоднозначные совпадения не угадываются.

### Решения по спорным местам

| Ситуация | Что делаем | Почему |
|----------|------------|--------|
| Закона нет в базе или он неоднозначен | ссылку не возвращаем, `law_id: null` не отдаём | лучше пропустить, чем ошибиться |
| Диапазон `43.2-6`, номер `4.6` | одна строка, не режем | так сказано в условии |
| `п.п. 3, 4 ст. 487` без отдельного пункта | пункты, а не подпункты | «п.п.» здесь сокращение «пункты» |
| `3.345, 23` | два пункта | запятая разделяет номера, точка нет |
| Одинаковые номера в перечислении | дубль убирается, порядок сохраняется | требование контракта `expand` |

## Как мы проверяем качество

Метрики считаются по кортежу `(law_id, article, point_article, subpoint_article)`, ссылки без закона не учитываются —
так же, как в сервисе. В таблице три разных по надёжности источника, их нельзя читать как одну цифру.

| Источник | Объём | F1 | Как читать |
|----------|-------|----|-----------|
| Отложенный набор `eval/holdout.py` | 45 кейсов | 0.990 при первом прогоне | написан уже после фиксации правил и не использовался для их подбора; единственная ошибка (перенос строки) исправлена, поэтому повторный прогон (1.000) уже не независим; автор набора тот же, что и автор правил |
| Сверка с моделью авторов `law-links` на фрагментах их опроса | 996 фрагментов | 0.935 (precision 0.970, recall 0.902) | эталон — ответы другой модели, а не люди; она тоже ошибается, а часть расхождений в том, что у фрагмента нет контекста |
| Наборы разработки: наш (33), внешний с реальными текстами (26), синтетика из базы законов (500) | 559 кейсов | 1.000 | по ним правились правила, поэтому это защита от регрессий, а не оценка качества |

Реалистичная ожидаемая точность на новых текстах — между вторым и первым рядом таблицы. Скрытые бенчмарки мы не видели.

```bash
cd homework_1
make test                                                           # pytest, 191 тест
python -m eval.run --local main:detect_links --holdout --tag holdout  # отложенный набор
python -m eval.survey                                               # сверка с опросом (скачивает ~2 МБ)
make eval                                                           # наборы разработки
```

Подробнее: [homework_1/eval/README.md](homework_1/eval/README.md).

## Скорость

Лимит проверки — 4 бенча по 500 текстов за 5 минут. Замеры по HTTP на локальной машине (`make speed`):

| Нагрузка | Время |
|----------|-------|
| 2000 текстов, в среднем 623 символа | 1.9 с |
| 2000 реальных текстов, в среднем 11 тыс. символов, самый длинный 27 тыс. | 4.4 с |

Запас по лимиту больше чем в 60 раз. Патологические строки (сотни тысяч пробелов, длинные тексты без ссылок, незакрытые кавычки) проверены тестом.

## Разработка

Работа разделена на пять ролей: поиск ссылок, определение закона, разбор номеров, сервис и инфраструктура, оценка качества.
Контракты между модулями зафиксированы в `contracts.py`; изменения контрактов вносятся только по согласию всех участников.

```
homework_1/
├── main.py, contracts.py, link_extractor.py, law_matcher.py, number_parser.py
├── law_aliases.json         база законов (1055 актов)
├── tests/                   pytest: модули, регрессии, эталон, HTTP-слой
├── eval/                    эталоны, метрики, запуск оценки, синтетика, отложенный набор, сверка с опросом
├── scripts/speed.py         замер скорости
└── Dockerfile, Makefile, requirements*.txt
.github/workflows/ci.yml     тесты, оценка, скорость, сборка образа и smoke-запрос
```

## Ограничения

- Закон, названный за пределами предложения со ссылкой, не определяется, такая ссылка пропускается.
- Неоднозначные названия (`Указ Президента России №490` у нескольких актов) не угадываются.
- Редкие формы и опечатки внутри самого названия закона могут не сработать.
- Абзацы (`абз. 2`) не выделяются отдельным уровнем: формат ответа их не предусматривает.
