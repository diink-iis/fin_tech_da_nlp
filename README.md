# fin_tech_da_nlp

## Групповое задание №1: сервис выделения юридических ссылок

Условие задания — в [homework_1/README.md](homework_1/README.md).

FastAPI-сервис принимает текст и возвращает найденные в нём юридические ссылки
(`law_id`, `article`, `point_article`, `subpoint_article`). Перечисления разворачиваются:
`пп. 1, 2, 3 п. 2 ст. 3 НК РФ` даёт три ссылки.

## Быстрый старт

### Docker

```bash
cd homework_1

docker build -t law-links-service .
docker run -d -p 8978:8978 --name law-links-container law-links-service

curl -X POST "http://localhost:8978/detect" \
     -H "Content-Type: application/json" \
     -d '{"text": "В соответствии с пп. 1, 2, 3 п. 2 ст. 3 НК РФ"}'
```

Ответ:

```json
{
  "links": [
    {"law_id": 15, "article": "3", "point_article": "2", "subpoint_article": "1"},
    {"law_id": 15, "article": "3", "point_article": "2", "subpoint_article": "2"},
    {"law_id": 15, "article": "3", "point_article": "2", "subpoint_article": "3"}
  ]
}
```

Готовность: `curl http://localhost:8978/health`. Документация API: http://localhost:8978/docs.
Сервис стартует за ~3 секунды (строится индекс названий законов), контейнер занимает ~95 МБ памяти,
образ — ~260 МБ, запускается не от root, есть `HEALTHCHECK`.

Остановка и удаление: `docker stop law-links-container && docker rm law-links-container && docker rmi law-links-service`.

### Без Docker

```bash
cd homework_1
pip install -r requirements.txt     # для разработки: requirements-dev.txt
python main.py                      # или: make run
```

## Как это работает

Запрос проходит конвейер из трёх модулей, которые связывает `detect_links` в `main.py`:

```
текст → extract_links → RawLink → find_law + expand → LawLink → ответ
```

| Файл | Что делает |
|------|------------|
| `contracts.py` | общий тип `RawLink` — ссылка с сырыми значениями уровней |
| `link_extractor.py` | `extract_links(text)` — находит ссылки и режет их на уровни; вырезает название закона |
| `law_matcher.py` | `find_law(law_text)` — по названию закона находит `law_id` |
| `number_parser.py` | `expand(raw, law_id)` — разворачивает перечисления в отдельные ссылки |
| `main.py` | FastAPI-приложение и конвейер `detect_links` |
| `tests/`, `eval/`, `scripts/` | тесты, эталоны и метрики, замер скорости |

Модули друг друга не импортируют, объединяет их только `detect_links`.

**Поиск ссылок** — правила на регулярных выражениях: токены уровней (`ст.`, `статья`, `п.`, `пункта`, `ч.`,
`пп.`, `подп.` в разных падежах и с опечатками), два порядка записи (`пп. 1 п. 2 ст. 3` и
`ст. 3 ч. 2 п. а`), значения вида `12`, `4.6`, `43.2-6`, `1, 2, 3`, `5 и 6`, `«б»`, «части первой».
Название закона вырезается справа от ссылки: кодексы и аббревиатуры (`УК РФ`, `ук рф`), законы и указы
с датой и номером (`Федерального закона от 27.07.2006 № 149-ФЗ «…»`), распоряжения, стандарты бухучёта.
Если закон справа не назван, берётся закон из контекста: `настоящего Федерального закона`,
`названного Кодекса`, `Согласно УК РФ … ст. 105` (в пределах предложения).

**Определение закона** — названия из `law_aliases.json` нормализуются и лемматизируются (pymorphy3),
индекс строится один раз при старте. Поиск идёт по точному совпадению, затем по самому длинному
однозначному вхождению, затем по номеру акта (`№ 580-ФЗ`) с уточнением по дате или названию.
Неоднозначные совпадения не угадываются.

### Принятые решения

- **Ссылки на неизвестный закон не возвращаются.** Если закона нет в `law_aliases.json`
  (Конституция, «рандомный кодекс», `ФЗ №20-456`) или его не удалось определить однозначно,
  ссылка пропускается: лучше пропустить, чем ошибиться. `law_id: null` сервис не отдаёт.
- Диапазоны (`43.2-6`) и номера с точкой (`4.6`) не разбиваются и остаются одной строкой.
- `п.п. 3, 4 ст. 487` без отдельного пункта читается как пункты, а не подпункты.
- `3.345, 23` — два пункта, поэтому «подпункты а, б и с пункта 3.345, 23» дают 6 ссылок.
- Перечисления раскрываются декартовым произведением, дубли убираются, порядок сохраняется.

## Проверки

```bash
cd homework_1
pip install -r requirements-dev.txt

make test        # pytest: 191 тест
make eval        # P / R / F1 по эталонам без запуска сервиса
make speed       # 2000 текстов по HTTP против лимита 5 минут, сервис должен быть запущен
```

Без `make`: `python -m pytest -q`, `python -m eval.run --local main:detect_links --external --synthetic 500`,
`python -m scripts.speed`. Подробнее про оценку — в [homework_1/eval/README.md](homework_1/eval/README.md).
CI (`.github/workflows/ci.yml`) на каждый push запускает тесты, оценку и замер скорости,
затем собирает образ, запускает контейнер и делает запрос к `/detect`.

### Качество

F1 по полному кортежу `(law_id, article, point_article, subpoint_article)`; ссылки без закона
в оценке не учитываются, как и в сервисе.

| Набор | Кейсов | F1 |
|-------|--------|----|
| Наш эталон (README задания и свои примеры) | 33 | 1.000 |
| Эталоны [fpakhurov/law-links](https://github.com/fpakhurov/law-links): `gold`, `gold_real` (реальные судебные тексты), `gold_test` | 26 | 1.000 |
| Синтетика из `law_aliases.json`, в том числе родительный падеж | 500 | 1.000 |

**Оговорка.** Правила дорабатывались по ошибкам именно на этих наборах, в том числе на `gold_test`,
который у авторов был отложенным, поэтому цифры завышены и не говорят о качестве на скрытых бенчмарках.
Для грубой независимой проверки наш ответ сравнивался с ответами модели авторов на 1061 фрагменте
из их открытого опроса ([law-links-votes](https://huggingface.co/datasets/fpakhurov/law-links-votes)):
precision 0.97, recall 0.90. Это сравнение двух моделей, а не с разметкой людей, и большая часть расхождений
приходится на фрагменты, где закон назван вне фрагмента.

### Скорость

| Замер (по HTTP, локально) | Результат |
|---------------------------|-----------|
| 2000 текстов, средняя длина 623 символа | 1.9 с (0.9 мс на текст) |
| 2000 длинных реальных текстов, в среднем 11 тыс. символов, до 27 тыс. | 4.4 с (2.2 мс на текст) |
| Лимит проверки: 4 бенча × 500 текстов | 300 с |

Запас по лимиту — более чем в 60 раз. Устойчивость к патологическому вводу (длинные строки без ссылок,
сотни тысяч пробелов, незакрытые кавычки) проверена тестом.

## Ограничения

- Закон, названный только в другом абзаце или вне пределов предложения, не определяется (ссылка пропускается).
- Неоднозначные названия (`Указ Президента России №490` у нескольких актов) не угадываются.
- Склонения внутри названия закона обрабатываются через лемматизацию, но редкие формы и опечатки
  в самом названии могут не сработать.
- Спорные трактовки (`п. "з"` — пункт или подпункт, диапазоны) выбраны по условию задания и README.
