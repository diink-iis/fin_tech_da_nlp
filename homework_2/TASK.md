# Проект №2

Разработка web-приложения, агрегирующего новости из RSS-лент по заданным тематикам и ключевым словам.

Необходимо написать web-приложение, фильтрующее новости из RSS-лент и отображающее только отфильтрованные новости в онлайне.
Необходимо обеспечить интерфейс для гибкого добавления фильтров (ключевые слова/темы).
Каждая новость должна быть помечена примененными фильтрами и техническими критериями фильтрации (чтобы понимать почему конкретная новость присутствует в выдаче).
Так же необходимо реализовать свой тестовый RSS канал, в который из интерфейса можно постить новые статьи, попадающие в поток новостей приложения.
Разбейтесь на команды не более 6 человек.

## Процесс приёмки

- Команда показывает презентацию про архитектуру приложения и реализацию движков поиска/фильтрации.
- Один человек из команды на своём ноутбуке демонстрирует работу приложения.
  Показывает добавленные фильтры и отфильтрованную ленту, проверяется соответствие контента в ленте настроенным фильтрам.
- В свой тестовый RSS канал демонстрирующий пишет пост в соответствии с настроенными фильтрами. Проверяется появление поста в агрегируемой ленте.
- Через доступный интерфейс добавляются новые фильтры.
- Преподавателем дается ссылка на новый канал, сервис перезапускается и демонстрируется появление новостей из нового источника.

## Критерии приёмки

Оценка 6:
- реализован поиск по ключевым словам

Оценка 8:
- дополнительно реализован поиск по семантике

Оценка 10:
- реализовано приложение, поддерживающее фильтрацию для нескольких пользователей. Интерфейс позволяет создавать новых пользователей, каждому из которых можно создавать свои кастомные фильтры по ключевым словам и тематикам, сформировать перечень читаемых каналов, добавление новых.
  Для такой реализации весь процесс приёмки сводится к настройке приложения рандомным человеком из аудитории, добавления каналов для подписки и проверке работоспособности фильтров.
