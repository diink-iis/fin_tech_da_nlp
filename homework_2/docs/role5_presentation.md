# Основа презентации — роль 5


## Слайд 1. NewsFlow — персональный RSS-агрегатор
- RSS/Atom источники собираются в единую ленту.
- Пользователи задают персональные фильтры и подписки.
- В выдаче есть объяснение, почему новость прошла фильтрацию.

## Слайд 2. Архитектура
RSS источники → агрегатор (fetch, parse, deduplicate) → SQLite → FastAPI REST API → браузерный интерфейс.
Движки keyword и semantic вызываются API при формировании персональной ленты. SSE уведомляет браузер о ревизии; браузер повторно запрашивает `/news`.

## Слайд 3. Keyword engine
- Нормализация текста и морфологические леммы.
- `any` — OR; `all` — AND; `none` — NOT.
- Поля поиска настраиваются: заголовок и/или текст.
- UI отображает совпавшие слова/поле, когда причина присутствует в API.

## Слайд 4. Semantic engine
- Тема описывается естественным языком и примерами.
- Тексты превращаются в embedding-векторы локальной моделью.
- Используется cosine similarity и пользовательский порог.
- Score не является вероятностью; в UI показывается значение score и threshold.
- Локальная модель позволяет автономную демонстрацию после предварительной загрузки.

## Слайд 5. Пользовательский режим
- Несколько пользователей с независимыми подписками и фильтрами.
- Создание/изменение фильтров в UI без рестарта.
- Свой RSS канал: создание, пост, автоматическая подписка.

## Слайд 6. Демонстрация
1. Создать Аню, добавить фильтр «нефть», опубликовать пост.
2. Создать Бориса с фильтром «банк», показать изоляцию.
3. Изменить фильтр Бориса на «нефть» и показать динамическое появление статьи.
4. Добавить semantic-фильтр «Политика» и новость без прямого ключевого слова.
5. Показать SSE, источники, отписку и сохранение после перезапуска.

## Слайд 7. Ограничения и дальнейшая работа
- Качество semantic-фильтра зависит от модели, описания темы и порога.
- Score нельзя интерпретировать как процент уверенности.
- Оценка модели в проекте ограничена небольшим набором данных; независимый размеченный test set и человеческая проверка необходимы для научных выводов.
- Можно улучшить пакетную индексацию, preview API, работу с ошибками RSS и offline-доставку модели.
